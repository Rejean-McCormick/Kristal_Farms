# Target village dossiers

This directory contains active research inputs for the Kristal Farms target-village portfolio.

Rules:

- these files are research inputs, never web-runtime dependencies;
- inclusion is not ranking, selection, authorization, commitment, or bankability;
- `null` means not verified, not zero;
- approach/anchorage depths are not berth depths;
- no aircraft or heavy-module capacity may be inferred from runway length or marine depth alone;
- load limits remain `not_verified` until attributable structural/operational documentation is published;
- `pipelines/publish/build_target_villages_public.py` is the only supported promotion path into the public product artifact.
