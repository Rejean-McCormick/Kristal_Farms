# Hydrology research

Exploratory workspace for river, basin, hydrometric-station and hydro-resource questions that are **not yet part of the reproducible ingestion/publish path**.

Use this area for candidate discovery, source comparison, exploratory notebooks and method experiments.

Production/reproducible hydrology ingestion remains under:

- `pipelines/ingest/hydrology/`;
- `pipelines/ingest/hydro_geometry/`;
- `pipelines/validate/`;
- governed outputs under `data/processed/current` and `data/publish/current`.

A file placed here must not be imported by `apps/web` or treated as public evidence simply because it exists in the repository.
