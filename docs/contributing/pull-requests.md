# Pull requests

A good pull request answers:

- What changed?
- Why?
- What architecture/data contracts are affected?
- How was it tested?
- Does it change public data or permissions?
- Does it introduce or alter assumptions?
- Does it require an ADR?

## Review specialties

Depending on the change, request review from:

- frontend/cartography;
- geospatial/data engineering;
- domain/research;
- security/operations;
- scenario/modeling.

## AI-generated changes

AI-generated code is reviewed using identical standards. Large generated diffs should be broken into understandable units where possible.
