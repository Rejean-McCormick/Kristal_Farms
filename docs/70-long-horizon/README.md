# Long-Horizon Concepts

These documents describe optional capabilities that may become relevant **after** Kristal Farms proves durable energy/compute nodes and local operating value.

They are not required to justify or approve the first project and must not be presented as committed institutions, partnerships, immigration programs, settlements or public services.

The near-term project case remains centered on:

> **energy → protected community interface → flexible compute → fibre + practical logistics**

Long-horizon material is retained to define safeguards and possible future directions without allowing those concepts to overtake the energy/compute project.

## Areas

- `communities/` — possible future human/community infrastructure;
- `learning/` — training, research and academic-network concepts;
- `education/` — implementation gates and templates for any future education program;
- `governance/` — human-dignity safeguards for those optional programs.
