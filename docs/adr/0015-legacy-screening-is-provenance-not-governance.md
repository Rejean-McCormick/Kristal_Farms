# ADR-015 — Legacy screening is provenance, not current governance

## Status
Accepted

Legacy Tier 1/2/3/4 and old no-go language are preserved so their origin can be inspected, but current `system.governance_state` remains `screening_mode=unranked` and `ranking_allowed=false`. Public publish views omit legacy tiers by default. Legacy environmental concerns are `unverified` historical context until replaced or supported by current authoritative evidence.
