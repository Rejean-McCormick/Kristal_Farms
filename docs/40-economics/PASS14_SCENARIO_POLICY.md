# Pass 14 scenario policy

1. A benchmark is not a site cost.
2. Unknown cost is `UNPRICED`, never zero.
3. A positive reference frontier is not called savings.
4. Generation CAPEX is common/excluded in the architecture-differential test unless later engineering shows the generation concept changes.
5. Tenant compute hardware is not counted as avoided infrastructure.
6. Project NPV/IRR is blocked until a site dossier has complete engineering/commercial inputs.
7. No site ranking is enabled.
8. Regulatory treatment of dedicated/local generation remains an open legal/utility question.
