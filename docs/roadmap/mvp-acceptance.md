# MVP acceptance criteria

## Public understanding

A first-time visitor can understand that:

1. Kristal Farms does not assume remote village grids contain multi-MW spare compute capacity.
2. New renewable generation is the core supply concept.
3. Community service is protected/priority.
4. Compute is flexible and can be colocated strategically.
5. Fibre is the main value-export corridor.
6. External projects are references, not automatically Kristal Farms sites.
7. Some important questions remain unresolved and are visibly labeled.

## Technical credibility

A professional can verify that:

- sources are traceable;
- entities have stable IDs;
- evidence is distinct from geometry;
- layers are catalog-driven;
- data can be consumed outside the Web UI;
- public release versions are identifiable;
- assumptions are distinguishable from observations.

## Engineering quality

- public layers load from a scalable static/tile path;
- core data is not embedded in frontend constants;
- policy validation blocks ranking violations;
- Pass 8 import has repeatable QA;
- public/private publication checks exist;
- critical Showcase flows support reduced motion.
