# Hydro Resource Atlas method

**Research baseline:** 2026-08-30

## Objective

Build a defensible northern hydro atlas without turning map references into dam sites. The object of study is a **river research reach**, not a project.

## Evidence sequence

1. official named watercourse / hydrometric-station anchor;
2. official station drainage-area metadata;
3. authoritative station-basin polygon;
4. authoritative connected river flowline;
5. official hydrometric time series;
6. HRDEM terrain profile along the connected reach;
7. environmental + rights/governance joins;
8. port/road/fibre/logistics joins;
9. only then a site-specific intake/powerhouse concept;
10. only then project head, design flow, MW and project economics.

## Critical distinctions

- **Gauge point ≠ dam site.**
- **Station drainage area ≠ a hand-drawn watershed.**
- **Terrain drop ≠ hydraulic project head.**
- **Mean river flow ≠ design flow.**
- **Q × H screening ≠ feasible MW.**
- **Straight-line distance ≠ access route.**
- **Evidence completeness ≠ opportunity/suitability.**

## Current limitation

Official source families are registered, but the current canonical fixture does not yet contain accepted basin/river geometry for the full research set. Only official WSC station points are materialized as physical geometry. No synthetic watershed, river line, terrain profile or project site is permitted as fallback.
