# Next Phase — Corridor / Site Dossiers

Do **not** continue with a generic Pass 15. Select a small set of representative corridors and replace general proxies with site-specific evidence.

## Recommended dossier structure

1. **Corridor definition** — communities, watersheds, ports, existing/future road/fibre/electric infrastructure.
2. **Hydro resource** — official basin and connected river geometry, HYDAT/CEHQ records, seasonality, low-flow evidence, terrain profile.
3. **Concept alternatives** — intake/powerhouse possibilities, dam-side vs village-side vs hybrid compute, short electrical connection concept.
4. **Community / Indigenous governance** — rights, decision process, community energy priorities, ownership/benefit alternatives.
5. **Environment** — protected areas, fish/habitat, cumulative impacts, site-specific red flags and required studies.
6. **Marine / ground logistics** — actual project-cargo vessel, wharf structural limits, offload method, laydown, bridge/road/culvert route to site.
7. **Telecom** — exact carrier route, landing, capacity, redundancy, dark/wholesale availability and commercial terms.
8. **Compute pad** — power/cooling/fibre/security interface and tenant black-box boundary.
9. **Economics** — conventional export alternative vs Kristal architecture using current vendor/utility quotes, not only benchmark ratios.
10. **Decision gate** — reject, hold, advance to prefeasibility.

## Suggested first portfolio

Use a deliberately diverse set rather than choosing a “winner” immediately:

- one Côte-Nord/Basse-Côte-Nord corridor suitable for pilot learning;
- one farther-north Québec corridor where road/HV avoidance is structurally important;
- one Labrador corridor with different utility/telecom/logistics conditions.

The purpose is to test the architecture across contrasting conditions and learn which variables actually dominate.
