# Canonical repository state

**Effective:** 2026-08-30

## One repo

`kristal-farms` is the single canonical repository for Kristal Farms research, evidence, application architecture, schemas, database, pipelines, contracts, public releases and future implementation code.

`Kristal_Farms.wiki` is the only intentionally separate repository.

## Superseded split

The temporary split between `kristal-farms-docs` and `kristal-farms` is superseded. It existed to support research passes, not because the product has two canonical systems.

## Kristal boundary

Kristal Farms and Kristal/Kristals are separate projects. Kristal Farms is not a hosting platform dedicated to Kristals; Kristals do not require Kristal Farms.

## Source of truth

For the implemented application, PostGIS is intended to be the operational source of truth. Research source files remain immutable/provenanced evidence inputs. Public files under `data/publish/` are release artifacts.

## Research state

Passes 1–14 form the completed horizontal research baseline. Subsequent work should be organized as corridor/site dossiers, implementation milestones or governed product releases rather than generic Pass 15+ research.
