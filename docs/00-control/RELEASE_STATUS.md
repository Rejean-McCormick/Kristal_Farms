## What “v3 released” means

A v3 partner release requires:

1. disposition of the strategic decisions relevant to that release;
2. evidence/caveats for claims promoted into external text;
3. partner-package Markdown rebuild;
4. synchronized French content;
5. regenerated selected PDFs/DOCX or a deliberate Markdown-only release decision;
6. updated data-room index and share manifest;
7. QA for links, citations, numeric consistency, confidentiality and v1/v2/v3 contradictions.
