# Current canonical fixtures

This directory contains the current cumulative fixture set used by the Kristal Farms data model and automated tests. It is a development fixture, not a declaration of site feasibility.

Key rules:

- screening is unranked;
- missing geometry remains null;
- planning margin is not compute-hosting capacity;
- project head, design flow and buildable MW are not inferred automatically;
- economic benchmarks are not site-cost estimates;
- source and evidence lineage must remain inspectable.
