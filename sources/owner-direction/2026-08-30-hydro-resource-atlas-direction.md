# Owner Direction — Hydro Resource Atlas

**Captured:** 2026-08-30  
**Class:** owner direction for research method, not independent hydro evidence.

Kristal Farms should build a broad map of northern river potential using one structured file per layer and a strict non-hallucination rule. The public objective is eventually to show the possible **chapelet** of hydro/compute/port/fibre nodes around Québec and Labrador, but the research map must begin from technical evidence.

Current method:

- ingest official basin, river and elevation geometry where possible;
- preserve missing geometry as `null`;
- distinguish river/gauge/reach from a dam site;
- calculate terrain metrics only after connected flowline geometry exists;
- calculate project head/MW only after a site concept exists;
- use colour or evidence classes for documentation maturity, not unvalidated site quality;
- maintain unranked screening until enough hydrology, environment, rights/governance, logistics, fibre and economics are available.
