# Repository tools

Operational and specialist developer utilities live here so the repository root remains a small set of canonical entry points and governance files.

- `observatory/` — diagnostics and Observatory support utilities.
- `imagery/` — PMTiles and local/satellite imagery helpers.
- `geospatial/` — specialist geospatial acquisition utilities.
- `update/` — repository update/wipe helpers when present in an update pack.

The canonical post-update launcher remains `REBUILD_OBSERVATORY.pyw` at repository root; `START_OBSERVATORY.bat` remains the quick-start launcher.
