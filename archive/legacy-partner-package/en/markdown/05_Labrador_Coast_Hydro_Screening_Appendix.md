## 1. Purpose

This appendix screens hydroelectric opportunities relevant to the Kristal Farms Labrador coast thesis.

The goal is not to produce a final engineering study. The goal is to identify which hydro opportunities are aligned with the project model and which opportunities should be excluded before partner time is spent on them.

Kristal Farms is focused on **coastal-accessible, community-scale hydro / compute / heat opportunities**, beginning with **Nain** and then replicating along the Labrador coast where the same conditions exist.

The project is **not** pursuing inland megaprojects, long-distance transmission plays, or large dam development as the first route to market.

## 3. Screening Thesis

Kristal Farms should screen hydro opportunities using the following thesis:

> **Use local coastal hydro to power village-sited compute pads, recycle server heat locally, and export compute outputs by fibre instead of exporting electricity over long transmission lines.**

This leads to four practical rules.

### Rule 1 — The compute pad should be near heat users, not at the dam

The current heat architecture is village-first. Containers should sit near the village, port, public buildings, housing clusters, and greenhouse heat sinks. A short medium-voltage feed can connect the hydro source to the village substation.

A site is weaker if it requires containers to sit far from heat users, because the main community value is lost.

### Rule 2 — Export compute, not electrons

The model avoids long high-voltage transmission corridors. The hydro source powers the local pad yard and community load. Results move by fibre.

A site is weaker if the main value depends on exporting power over long transmission lines.

### Rule 3 — Heat value matters as much as hydro capacity

Hydro potential alone is not enough. A site should have nearby useful heat demand:

- clinic;
- school;
- municipal buildings;
- housing clusters;
- domestic hot-water preheat;
- greenhouse heat demand;
- thermal storage potential.

A site with strong hydro but no heat sink is less aligned with the Kristal Farms partner package.

### Rule 4 — The first project should be modular and reversible

The first site should allow staged deployment:

1. site validation;
2. community/FPIC process;
3. hydro and grid pre-feasibility;
4. fibre and logistics design;
5. pilot pad;
6. heat loop and greenhouse;
7. expansion pads.

Sites that require one large irreversible capital decision before proof of value are less suitable for the first wave.

## 4. Screening Criteria

Each hydro candidate should be scored against the following criteria.

| Criterion | Question | Strong signal | Weak signal |
|---|---|---|---|
| Hydro resource | Is there enough year-round flow and head? | Preliminary 15–20 MW+ potential with winter-flow path to validation | Only theoretical annual flow; no winter-flow data |
| Seasonal reliability | Can the site support winter operation? | Documented under-ice flow, frazil management plan, seasonal flow curve | High spring/summer flow only; winter uncertainty |
| Coastal access | Can heavy equipment arrive by sea? | Port, sheltered landing, crane plan, short road route | Long inland road, difficult overland transport |
| Distance to village | Can power reach a village substation by short MV line? | Short MV route, no long HV corridor | Long transmission line needed |
| Heat users | Are heat sinks close to the pad yard? | Public buildings, housing, greenhouse site, short heat loop | No concentrated heat demand |
| Fibre path | Can compute outputs be exported reliably? | Existing/planned fibre, redundancy path, NOC concept | No credible fibre path |
| Environmental sensitivity | Can impacts be minimized? | Run-of-river, small/no reservoir, non-contact cooling, limited inundation | Large reservoir, protected habitat, fish/marine conflicts |
| Community consent | Can FPIC and benefit-sharing proceed credibly? | Clear governance pathway and local benefit case | Unclear consent structure or unresolved land issues |
| Constructability | Can the work fit northern construction windows? | Seasonal marine logistics plan, modular components | Complex civil works, long exposed schedule |
| Replicability | Does the site teach a repeatable model? | Coastal village + hydro + port + heat + fibre pattern | One-off special case |

#### Why Nain is first

Nain is the correct first target because it aligns with all major Kristal Farms filters:

1. **Labrador coast focus** — it is a coastal Labrador community, not an inland megaproject.
2. **Specific hydro candidate** — the current source package identifies the Fraser River candidate.
3. **Community-scale range** — the preliminary 15–20 MW range fits modular compute plus local load better than a mega-dam frame.
4. **Port logic** — equipment can be planned around marine logistics.
5. **Heat-first model** — the village contains the heat users; containers should be placed near public buildings, housing, and greenhouse users.
6. **Replication logic** — if the pattern works in Nain, other Labrador coast communities can be screened using the same template.

The following items must be validated before Nain is presented as investment-ready:

- monthly and seasonal flow profile;
- winter low-flow and under-ice flow availability;
- frazil ice and intake-freezing risks;
- usable head and penstock route;
- run-of-river design feasibility;
- reservoir/pondage footprint, if any;
- fish passage and aquatic habitat impacts;
- geotechnical conditions at intake, powerhouse, road, and substation sites;
- route and cost of MV connection to the village substation;
- port landing and heavy-lift capacity;
- road-access route from port/village to hydro works;
- fibre availability and redundancy plan;
- local heat-load inventory;
- FPIC and Nunatsiavut governance pathway;
- updated cost estimate with northern contingency.

## 6. Excluded or Deferred Site Categories

### 6.1 Inland megaprojects

Large inland hydropower assets and large transmission-oriented opportunities should be excluded from the first partner package.

Examples include:

- Churchill Falls;
- Muskrat Falls;
- Gull Island or other large-scale Labrador hydro concepts.

These assets may be strategically important in a broad Canadian energy discussion, but they are not the Kristal Farms first-wave model.

Reasons for exclusion:

- they are not village-scale coastal replication opportunities;
- they imply large institutional power-sector structures;
- they can distract from the Nain-first thesis;
- they generally do not solve the heat-reuse problem for coastal villages;
- they can pull the conversation toward grid export rather than compute export.

Partner-facing rule:

> **Kristal Farms is not pursuing mega-dams or inland transmission projects as its first route to market.**

---

### 6.2 Existing operating or already-planned hydro assets

Operating or already-committed hydro projects may be relevant as comparables, but should not be treated as Kristal Farms target sites unless there is a clear new pad, heat, and fibre opportunity.

Examples from the broader source material include:

- Innavik / Inukjuak as a useful remote-hydro precedent;
- Iqaluit / Kuugaluk as a useful Arctic hydro planning precedent.

These are **case studies**, not Labrador coast target sites.

### 6.3 Nunavik mega-river concepts

Examples include:

## 7. Hydro Evaluation Method

The source hydro methodology is based on a practical hydro-screening logic: flow, head, seasonality, winter operability, access, environmental acceptability, and social legitimacy.

### 7.1 Hydrologic resource

The first technical question is whether the river has enough usable flow.

Required data:

- watershed area;
- precipitation and snowmelt pattern;
- monthly flow curve;
- annual average flow;
- winter low-flow estimate;
- flood-frequency data;
- climate-change sensitivity;
- uncertainty range.

The key partner question is not “what is the theoretical annual capacity?”

The key partner question is:

> **How much reliable power is available when the village and compute campus need it, especially in winter?**

---

### 7.2 Head and site geometry

The second technical question is whether the river has enough exploitable head without creating a large reservoir.

Required data:

- topographic profile;
- LiDAR or photogrammetry;
- rapids / falls / constriction inventory;
- possible intake location;
- possible powerhouse location;
- penstock route;
- road route;
- geotechnical and bedrock conditions.

A strong Kristal Farms site should have a useful head/flow combination that supports a **run-of-river or low-pondage design**.

A weak site requires large inundation, long canals, or major civil works before a modest amount of dependable power can be produced.

---

### 7.3 Power estimate

For early screening, the power estimate can be approximated from:

```text
P = ρ × g × Q × H × η
```

Where:

- `P` = power output;
- `ρ` = water density;
- `g` = gravitational acceleration;
- `Q` = flow;
- `H` = head;
- `η` = efficiency.

For practical pre-screening, the source document uses the rule of thumb:

```text
P(kW) ≈ 7 to 8 × Q(m³/s) × H(m)
```

This should be treated as a **screening estimate only**, not an investment-grade capacity claim.

---

### 7.4 Winter operability

Northern sites require a dedicated winter-operability screen.

Required checks:

- river ice cover;
- anchor ice;
- frazil ice;
- intake clogging;
- minimum flow under ice;
- access to intake in winter;
- line and substation reliability;
- emergency diesel/battery backup;
- seasonal maintenance windows.

A site that looks strong on annual average flow can fail if winter low flow is too weak or if intake icing cannot be managed.

---

### 7.5 Environmental acceptability

Environmental screening should be completed before any partner-facing claim that a site is “low impact.”

Required checks:

- fish habitat and fish passage;
- salmonid / Arctic char / migratory species issues;
- wetlands;
- marine outlet impacts;
- protected areas;
- bird and terrestrial habitat;
- archaeological/cultural sites;
- permafrost and terrain disturbance;
- mercury/methylmercury risk if pondage is created;
- cumulative effects;
- construction sediment controls;
- environmental flow requirements.

A site should be preferred if it can use a low-impact design with minimal inundation and a clear environmental flow plan.

---

### 7.6 Coastal logistics

Coastal access is a core criterion, not a minor construction detail.

Required checks:

- sealift window;
- berth and draft limits;
- crane/heavy-lift capacity;
- temporary landing possibility;
- staging area near port;
- route from port to hydro works;
- bridge and culvert needs;
- fuel, camp, and equipment storage;
- weather delay contingency;
- demobilization and reversibility.

A site should be downgraded if heavy equipment requires a long new road, repeated overland hauling, or construction outside reliable seasonal windows.

---

### 7.7 Electrical integration

The preferred project architecture is a short MV connection from hydro to a village substation.

Required checks:

- route length;
- voltage level;
- right-of-way;
- substation location;
- power quality;
- protection coordination;
- pad metering;
- reserve margin for community load;
- emergency backup arrangements;
- expansion capacity.

Sites requiring long HV lines are not aligned with the first package.

---

### 7.8 Compute, fibre, and heat fit

Hydro screening must be connected to the compute and heat model.

Required checks:

- pad yard location near port or village edge;
- fibre route and redundancy;
- NOC location;
- public-building heat demand;
- housing heat demand;
- greenhouse site;
- thermal storage area;
- cold-source access at bay/port;
- non-contact heat rejection feasibility;
- winter and summer heat-sink balance;
- public dashboard and metering plan.

A hydro site should not be ranked highly unless it can support **power + fibre + heat reuse + community governance** together.

## 9. Required Next Studies

### 9.1 Nain / Fraser River — immediate diligence package

The Nain diligence package should be organized as follows.

#### A. Hydrology

- install or obtain stream-gauge data;
- build monthly flow model;
- calculate winter firm flow;
- estimate annual energy production;
- model climate sensitivity;

#### B. Topography and geotechnical

- LiDAR survey;
- intake/powerhouse reconnaissance;
- penstock route survey;
- road-access alignment;
- bedrock and foundation investigation;
- permafrost and slope-stability screening.

#### C. Environmental baseline

- fish habitat;
- spawning areas;
- marine outlet conditions;
- wetlands and riparian zones;
- wildlife and bird use;
- archaeological and cultural sites;
- mercury/methylmercury risk if pondage is used;
- construction sediment control.

#### D. Community and FPIC

- identify decision-making bodies;
- define FPIC process timeline;
- define information-sharing process;
- define benefit-sharing principles;
- define grievance process;
- define local employment/training pathway;
- define heat allocation priorities.

#### E. Port and logistics

- confirm quay/landing capacity;
- confirm crane/heavy-lift needs;
- map staging area;
- define sealift schedule;
- define temporary road needs;
- price mobilization and demobilization;
- create weather-delay contingency.

#### F. Electrical integration

- select MV voltage concept;
- define hydro-to-village feeder route;
- identify village substation site;
- define pad-level metering;
- define protection coordination;
- define emergency backup and black-start requirements.

#### G. Fibre and compute operations

- confirm southbound fibre path;
- assess redundancy and outage risk;
- define NOC requirement;
- define pad bandwidth assumptions;
- define tenant black-box boundary;
- define service monitoring fields.

#### H. Heat and cold-source integration

- inventory public-building heating systems;
- measure current fuel use and heat demand;
- identify first heat customers: clinic, school, municipal buildings;
- assess housing cluster extensions;
- identify greenhouse location;
- confirm bay/seawater non-contact cooling concept;
- size first thermal storage tank;
- define HUF, MWh-th, PUE, WUE, diesel-avoided metrics.

## 10. Evidence Standards

The partner package should use three evidence labels.

### Confirmed

Use only when supported by verified documents, public records, engineering studies, or signed partner/community information.

### Preliminary

Use for claims supported by source material but not yet independently validated.

Example:

> “The Fraser River candidate near Nain is treated as a preliminary 15–20 MW opportunity based on the current source package, subject to hydrology, engineering, environmental, cost, and community validation.”

### Open / To validate

Use for all replication communities until a specific candidate river and site geometry are identified.

Example:

> “Hopedale is included as a replication-screening community. A specific hydro candidate has not yet been validated in the current source package.”

## 12. Language to Avoid

Avoid the following in partner-facing materials:

- “Hydro site confirmed” unless engineering validation is complete.
- “Guaranteed 15–20 MW” for Nain.
- “Year-round marine access” unless specifically validated.
- “No environmental impact.”
- “Community consent secured” unless formally true.
- “Nain model applies automatically to all Labrador communities.”
- “Churchill Falls / Muskrat Falls / Gull Island are target sites.”
- “Nunavik mega-river opportunities are part of the first package.”
- Any unverified cost, revenue, IRR, tariff, or PUE claim.
