# Superseded working name

These files preserve Pass 11–14 provenance from the period when the application/data-model work used the working name **Kristal Platform / Kristal Geospatial Platform**.

That name is superseded. The canonical product and repository are **Kristal Farms**. These files do not describe a system for semantic Kristals and do not imply any dependency between Kristal Farms and Kristal/Kristals.

Current application architecture lives under `docs/architecture/`, `docs/data/`, `docs/product/`, `contracts/`, `database/`, `pipelines/` and `packages/`.
