# Pass 14 economic method

## Question
For the **same remote generation opportunity**, what infrastructure burden is associated with:

A. long electrical export + long road access; versus
B. local digital-value export, represented initially by northern fibre funding-intensity proxies, with Kristal-specific local infrastructure left explicitly unpriced?

## Evidence band
Transmission project-total ratios:
- Chamouchouane–Bout-de-l’Île: C$1.3B / 439 km = C$2,961,276/line-km (includes substation and project scope).
- Micoua–Saguenay: C$1.271B / 262 km = C$4,851,145/line-km.

Northern road ROM references:
- C$2.1B / 809 km = C$2,595,797/km before paving.
- C$2.7B / 809 km = C$3,337,454/km including stated paving increment.

Northern fibre funding-intensity proxies:
- Nunavik: C$79.419M / 933 km = C$85,122/km.
- Nunavut: C$271.937M / 1,300 km = C$209,182/km.

These are **not interchangeable unit construction costs**. Pass 14 uses them only to construct a reference frontier.

## Frontier
For each non-site stress case:

`conventional_low = HV_km × transmission_low + road_km × road_low`

`conventional_high = HV_km × transmission_high + road_km × road_high`

`fibre_proxy_low/high = fibre_km × fibre_funding_proxy_low/high`

`conservative remaining budget = conventional_low − fibre_proxy_high`

`optimistic remaining budget = conventional_high − fibre_proxy_low`

A positive value is **not savings**. It is the maximum envelope remaining, on these reference components, for all still-unpriced Kristal-specific infrastructure before parity.
