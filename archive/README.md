# Archive

This directory preserves superseded research, historical drafts, source extractions, old data snapshots and repository-assembly artifacts for provenance and reproducibility.

**Nothing in `archive/` is authoritative merely because it is retained here.** Active project direction, methods, application contracts and current data live outside this directory.

Main categories include:

- `internal-research-history/` — internal research chronology and process records;
- `research-snapshots/` — older structured-data and analysis snapshots;
- `research-pipelines/` — superseded pipeline versions retained for reproducibility;
- `legacy-partner-package/` and `legacy-partner-research/` — superseded partner-facing material;
- `legacy-economics/` — older economic analyses that do not meet current benchmark/assumption discipline;
- `legacy-map-data/` — historical cartographic inputs and screening layers;
- `legacy-source-extractions/` — searchable extractions removed from active documentation;
- `superseded-reference-docs/` — reference or strategy documents replaced by current architecture;
- `owner-direction-history/` — superseded project-direction records;
- `internal-build/` — repository assembly and QA handoff artifacts;
- `naming-superseded/` — material preserved under earlier product/repository naming;
- `source-packages/` and `pre-refactor/` — source and repository states retained before normalization.

Historical files may contain terminology, assumptions, rankings or claims that are no longer current. They must not silently re-enter active project state.
