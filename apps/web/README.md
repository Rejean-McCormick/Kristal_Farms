# Web application

Implementation home for the Kristal Farms **Showcase**, **Explorer** and **Scenario Studio**.

## Observatory Explorer v0.2 — Geographic Observatory

The repository includes a working implementation of the map interaction specification in [`../../docs/frontend/map-observatory-interaction.md`](../../docs/frontend/map-observatory-interaction.md).

Implemented in v0.2:

- Next.js + TypeScript application shell;
- MapLibre GL JS v6 map canvas and explicit worker handling for Next/Turbopack;
- keyless OpenFreeMap/OpenMapTiles development basemap, recolored into the Observatory visual language;
- governed public communities and hydrometric stations read server-side from `data/publish/current`;
- 24 governed river research references derived from `hydro_evidence_matrix_public.json` and linked station anchors;
- contextual vector hydrography hover from the basemap, clearly separated from governed Kristal geometry;
- matching of contextual river names to Kristal river research entities without fabricating river flowlines;
- multi-scale community/station symbology, focus rings and labels;
- proximity, delayed hover, selected, related, compared and dimmed map feature states;
- river, station and community search;
- persistent evidence-first Entity Inspector;
- dedicated Hydrology / Engineering-gates inspector section for river-linked records;
- human-readable public evidence claims and source links from `evidence_records_public.json`;
- non-geographic relation constellation inside the Inspector;
- URL state for camera, selected entity and comparison pins;
- map HUD, release telemetry, layer controls and context-label toggles;
- keyboard-focus targets that trigger the same recognition surface as pointer hover;
- mobile Inspector treatment and reduced-motion support.

### Geometry semantics

The basemap can show and highlight contextual river lines from OpenMapTiles/OpenStreetMap. Those lines are **context only**. They do not become Kristal river geometry.

River entities remain explicitly `authoritative_flowline_not_ingested` until the data platform publishes an accepted connected flowline. External reference projects with `geometry: null` remain panel-only. Conceptual corridors remain `panel_only` per `packages/shared/visual_semantics.json`.

## Run locally

From this directory:

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

The development basemap defaults to the OpenFreeMap Liberty vector style and is recolored at runtime. To use an approved/self-hosted MapLibre style instead:

```bash
NEXT_PUBLIC_BASE_STYLE_URL="https://your-style-host/style.json"
```

The MapLibre v6 worker files are copied into `public/maplibre/` by the `predev` and `prebuild` hooks.

## Publication helper

Human-readable evidence records are generated by the data-platform publication helper:

```bash
python pipelines/publish/build_observatory_public.py
```

This reads governed canonical fixtures during the publication step and writes only the public artifact consumed by the product:

```text
data/publish/current/evidence_records_public.json
```

## Data boundary

The client does **not** embed canonical community/station fixtures as React constants. Route handlers under `app/api/explorer/` read the current public release server-side, while stable layer metadata comes from `packages/catalog`. The Web application does **not** read `research/`, `pipelines/`, `data/raw/` or `data/fixtures/` at runtime.

```text
research
   ↓ explicit promotion
pipelines / contracts / validation
   ↓ publish
 data/publish/current + packages/catalog
   ↓ read only
apps/web / Observatory
```

Contextual basemap hydrography is a visual/navigation aid and is not promoted into the governed data contract by the frontend.


## Local satellite imagery

The Observatory does not use a paid/runtime satellite API. High-resolution
photographic context is served from a static tile snapshot under
`public/imagery/`.

Build or replace the local snapshot with:

```powershell
python ..\..\pipelines\imagery\build_local_satellite.py `
  ..\..\data\source\imagery\YOUR_IMAGE.tif `
  --id local-satellite `
  --replace
```

See `docs/frontend/offline-satellite.md` and `pipelines/imagery/README.md`.
