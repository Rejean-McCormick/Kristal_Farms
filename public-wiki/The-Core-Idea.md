# The Core Idea

Conventional remote-energy development often starts with this question:

> How do we move electricity from a remote renewable resource to an existing load centre?

Kristal Farms asks a different question:

> **Can we move the load to the energy, use the electricity on site, and export the value digitally?**

That inversion changes the infrastructure stack.

## Conventional direction

**Remote generation → long electrical corridor → distant load**

This can require high-voltage lines, substations, rights-of-way, clearing, roads, maintenance access and transmission losses.

## Kristal Farms direction

**Renewable resource → short local electrical connection → modular compute → fibre export**

The compute produces a second local product: **heat**. Rather than treating server heat as waste, the baseline design routes it to buildings, domestic hot-water preheat, greenhouses, storage or other useful sinks before rejection.

## The qualifying rule

Kristal Farms is not intended for every river or every northern site. A site should advance only if the full system demonstrates a compelling advantage after accounting for:

- generation;
- local power connection;
- compute infrastructure;
- cooling and heat recovery;
- fibre;
- logistics;
- environmental effects;
- community process;
- reliability;
- lifetime economics.

In other words, **structural advantage is a site-selection requirement, not a marketing afterthought**.
