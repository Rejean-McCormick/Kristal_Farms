# Kristals: A Knowledge Commons

The internal reference includes a separate concept called **Kristals**: reusable, validated knowledge capsules.

The idea is to recycle intelligence in the same spirit that the physical project recycles heat.

## A Kristal can contain

- a clear question;
- a concise answer;
- sources;
- creation/update date;
- model/method information;
- validation status;
- version history;
- an integrity identifier or hash.

## Why reuse matters

If a high-quality answer already exists and remains current, retrieving it can avoid repeating expensive computation.

The project proposes metrics such as:

- number of Kristals published;
- hit rate;
- revisions;
- estimated compute avoided.

Kristals are a secondary knowledge-layer concept, not required for the first physical infrastructure pilot.
