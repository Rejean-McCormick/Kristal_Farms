# Licensing

No software or data license is selected by this documentation package.

Before public release, the repository maintainers should decide separately:

1. software source-code license;
2. documentation license if different;
3. licenses/terms for each published dataset;
4. attribution requirements for basemaps, tiles, imagery, and third-party sources;
5. whether some research data must remain non-redistributable despite being viewable.

Do not assume that because a source is publicly accessible its data can be republished without restriction.
